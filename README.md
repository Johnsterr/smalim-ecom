# smalim-ecom

E-commerce platform

## Features

- User authentication and authorization
- Product catalog management
- Shopping cart functionality
- Order processing and management
- Payment integration
- RESTful API built with FastAPI

## Commands

### Run the application

```bash
docker compose up -d
```

```bash
pipenv shell
```

```bash
uvicorn app.main:app --reload --port 8000
```
